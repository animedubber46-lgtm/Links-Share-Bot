# ✨ Link Share Bot ✨

> 🚀 A modern Telegram link sharing and management bot built with **Pyrogram** and **MongoDB**.

## 🌟 Highlights

* 🔗 Secure Telegram invite link generation
* 📺 Unlimited channel management
* ⏱️ Auto-expiring invite links
* 📦 Bulk link generation
* 🛡️ Force subscription support
* 📊 Bot statistics and admin tools
* ☁️ Easy deployment on VPS, Docker, or cloud platforms

## 🚀 Features

| Feature               | Description                               |
| --------------------- | ----------------------------------------- |
| 📺 Unlimited Channels | Add and manage multiple Telegram channels |
| 🔗 Auto Invite Links  | Generate secure invite links              |
| ⏱️ Auto Revoke        | Automatically expire links                |
| 📦 Bulk Generation    | Generate many links at once               |
| 📋 Pagination         | Browse channels easily                    |
| 🛡️ Force Subscribe   | Require channel membership before access  |
| 📊 Statistics         | Track users and bot activity              |

---

## 🛠️ Main Commands

```text
/addch        Add a channel
/delch        Remove a channel
/channels     View connected channels
/links        Generate links
/reqlink      Request links
/bulklink     Bulk link generation
/stats        Bot statistics
/status       Bot status
/broadcast    Broadcast messages
```
